关系回响

把 Windows 上的联系人安全迁到 Mac，并在本机生成一个独立 App。

  1. 先在 Mac 安装 Node.js 24 LTS，并保持联网。
  2. 确认你已经另外保存了“迁移密码与校验”文件；密码和可信 ZIP SHA-256 都不在这个 ZIP 里。
  3. 解压前先按私密校验文件中的命令核对 ZIP SHA-256；完全一致后，才双击 在Mac上构建关系回响.command。
  4. 完成后只需打开 ~/Applications/关系回响.app。数据保存在 ~/Library/Application Support/Relationship Echo。
如果 macOS 阻止第一次打开，请到“系统设置 → 隐私与安全性”确认“仍要打开”。这是个人本机构建包，Windows 端无法代替 Mac 完成 Apple 官方签名与公证。
