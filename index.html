支持哪些文件？
  • 关系回响通用数据源 JSON（format: relationship-care-source，见样例）
  • WeFlow 导出的会话 / 消息 JSON
  • 含姓名、最近消息、时间等字段的通用 CSV
  • 单文件最大 5 MB；群聊与公众号不进入名单

WeFlow 是 Windows 端的微信联系人提取器，这台 Mac 上没有它的 API。请先用「本机文件」导入 JSON / CSV，或者等读取器桥接接入。

WINDOWS 本机直连

用 WeFlow 提取联系人

先在 WeFlow 设置 → API 服务 里启动，再回到这里连接；只向 127.0.0.1 请求联系人、会话时间和最近一条消息。

Access Token 只驻留本次连接内存；不会写进 SQLite 或浏览器缓存。

Mac 读取器桥接（准备中）

选定 Mac 微信读取软件后，让它输出与「格式样例」相同的 JSON 合同即可接入；标签、提醒和整理功能不用改。当前请先用「本机文件」导入。

    RHYTHM SETTINGS

    节律设置

    阅读字号
    立即生效；只影响这台设备上的显示大小，不改变数据。
    提醒边界

    当前版本只在打开网站时计算到期状态。若需要关站后仍可靠提醒，应增加本地 Agent 或操作系统计划任务。
    DATA & PRIVACY

    数据与隐私

    本机 SQLite

    正式数据写入本机数据目录

    SQLite 是唯一权威来源；Windows 默认保存在项目同盘数据目录，Mac 默认使用 Application Support，也可自行指定路径。数据库：正在连接本机服务…

    滚动快照

    浏览器清理不再删除主数据

    每次变更保留历史，至少每小时或重大恢复时生成独立 SQLite 快照。最近备份：尚未创建

    可替换的数据源

    WeFlow 不是数据库，只是 Windows 提取器

    默认通过 127.0.0.1:5031 读取 WeFlow；Mac 可改用通用文件或未来的读取器桥接。Token 仅保留在当前操作内；状态：正在检查

    隐私边界

    本地不等于加密保险箱

    拥有这台电脑账户权限的人仍可能读取数据库；存储磁盘损坏也会影响同盘快照。关闭应用后不保证通知，重新打开时才会计算提醒。
